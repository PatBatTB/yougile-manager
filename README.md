# YouGile-Plugins Platform
___
## Plugin manager
___
___
### Description

Менеджер для запуска плагинов для `YouGile`
___

### Configuration

Настройки для менеджера плагинов указываются в файле `manager.congig.json`.

`manager` - обязательный объект, общие настройки менеджера плагинов.

`mail` - необязательный объект, может быть указан в конфиге, если необходимо отправлять оповещения по почте об ошибках.

Все вложенные объекты являются обязательными.

Опсиание конфиг-файла:
```json
{
  "manager": {
    "threads": <Число: Количество потоков для запуска плагинов>,
    "cycle": <Число: Время в секудах с какой периодичностью запускать плагины>,
    "terminationTimeout": <Число: Время в секундах, сколько ждать завершения работы плагинов перед принудительным шатдауном>
  },
  "mail": {
    "report": {
      "interrupted": <Булевый: Отпавлять ли оповещение при PluginInterruptedException>,
      "critical": <Булевый: Отправлять ли оповещение при PluginCriticalException>
    },
    "from": {
      "name": <Строка: Имя отправителя, указанный в письме>,
      "email": <Строка: Емаил отправителя, указанный в письме>
    },
    "recipients": [
      <Строка: Почта получателя оповещения>,
      <Строка: Дополнительная почта получателя>
    ],
    "smtp": {
      "host": <Строка: хост smtp сервера>,
      "port": <Число: порт smtp сервера>,
      "ssl": <Булевый: используется ли SSL>,
      "username": <Строка: логин от почты>,
      "password": <Строка: пароль от почты>
    }
  }
}
```

### Usage

#### Скачать готовый архив:
- Скачать архив с последней версией из [релизов](https://github.com/PatBatTB/yougile-manager/releases).
- Распаковать
- Указать настройки в конфиге `manager.config.json`
- В папку `plugins` положить jar-файлы плагинов.
- Добавить +x скрипту `start.sh` 
```bash
chmod +x ./start.sh
```
- запустить `strat.sh`

#### Собрать из исходников:
- Клонировать текущий репозиторий
- Собрать проект `mvn clean package`
- Забрать архив `yougile-manager-${current-version}-release.tar.gz`
- Распаковать
- - Указать настройки в конфиге `manager.config.json`
- В папку `plugins` положить jar-файлы плагинов.
- Добавить +x скрипту `start.sh`
```bash
chmod +x ./start.sh
```
- запустить `strat.sh`
